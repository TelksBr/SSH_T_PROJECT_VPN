## 📱 Sobre o App

**SSH T PROJECT VPN** é um aplicativo gratuito que oferece acesso à internet móvel através de conexões seguras via **SSH**, **V2RAY** e **Hotspot VPN**, pensado especialmente para pessoas com dificuldades de acesso à internet.

Nosso objetivo é oferecer **acesso gratuito à internet**, com servidores estáveis e atualizações constantes.

---

## 🚀 Principais Funcionalidades

✅ Conexão via **SSH** e **V2RAY**  
✅ **Servidores gratuitos e premium**  
✅ **Hotspot VPN** com proxy dedicado  
✅ Suporte a **UDP (chamadas, jogos, etc.)**  
✅ Atualizações frequentes  
✅ Aplicativo leve e fácil de usar

---

## 📋 Requisitos

- Android 8.0 ou superior  
- SIM card ativo (mesmo sem dados móveis)  
- Conexão com internet para a primeira atualização do app
